# Prompt 03: Spec

Cole no chat do Cursor (depois do plano aprovado):

```text
Plano aprovado. Agora escreva a Spec da feature. NÃO implemente código.

Use specs/TEMPLATE-feature.md.
Salve em: specs/YYYY-MM-DD-<slug-da-feature>.md

Regras da Spec:
- Linguagem de domínio (sem endpoint, tabela, classe)
- Caminho feliz + erros/bordas
- Cada cenário com linha Prova (comando/teste ou TC manual)
- Critérios de Done + escopo de arquivos permitido
- Status inicial: draft
- Small: spec curta. Não inventar tasks.md de 20 itens.

Ao terminar, peça minha aprovação explícita antes de qualquer implementação.
```
