# Prompt 04: Implementar

Cole no chat do Cursor (só depois da Spec aprovada):

```text
Spec aprovada: specs/<arquivo-da-spec>.md
Autonomia: <tight|medium|loose>

Implemente SOMENTE o que a Spec pede.

Regras:
1. Respeite AGENTS.md (pode / não pode)
2. Não altere a Spec
3. Package by feature / Deep Modules quando criar arquivo novo
4. Teste (se a Spec exigir) nasce do cenário. Deve falhar no código antigo.
5. Não edite teste legado para ficar verde
6. Não mexa em path crítico sem eu ter pedido
7. Ao final rode os comandos de Done do AGENTS.md
8. Antes de declarar Done, atualize docs vivos (skill close-phase)
9. Não escreva o parecer final de verificação: eu (ou o verifier) faço isso
```
